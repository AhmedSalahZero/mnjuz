# المحادثة المباشرة في موقعك — دليل التاجر

نافذة محادثة تظهر في موقعك أو متجرك. يكتب لك الزائر، فيردّ عليه **نفس الردّ الآلي الذي تستعمله في واتساب** (الردود الجاهزة والـ flows والمساعد الذكي)، وتصل المحادثة إلى **صندوق المحادثات نفسه** بتذاكرها وإسنادها، فيكمل موظّفك معه من الويب أو من التطبيق.

---

## ١. التفعيل

1. **الإعدادات ← المحادثة المباشرة** (تظهر إن كانت ضمن باقتك).
2. فعّل المفتاح أعلى الصفحة.
3. انسخ **كود التركيب** — سطر واحد:

```html
<script async src="https://app.mnjz.sa/widget/v1/loader.js" data-mnjz-key="wc_xxxxxxxxxxxxxxxxxxxxxxxx"></script>
```

## ٢. التركيب على منصّتك

الكود يُلصق **مرّة واحدة** فيظهر في كل صفحات الموقع، والأفضل قبل نهاية الـ `body`.

| المنصّة | المكان |
|---|---|
| **سلة** | لوحة التحكم ← المتجر ← الإعدادات ← الأكواد المخصّصة ← خانة الـ Footer |
| **زد** | الإعدادات ← إعدادات المتجر ← الأكواد الإضافية ← الـ Footer |
| **Shopify** | Online Store ← Themes ← Edit code ← `theme.liquid` ← قبل `</body>` |
| **WordPress** | إضافة لإدراج الأكواد (مثل WPCode) ← Footer، أو `footer.php` في القالب |
| **موقع خاصّ** | في القالب المشترك لكل الصفحات، قبل `</body>` |

> الكود خفيف (أقلّ من ٣ كيلوبايت)، ولا يُحمّل نافذة المحادثة الكاملة إلا حين يضغط الزائر — فلا يُبطئ موقعك.
>
> أسفل خانة الكتابة سطر صغير «بواسطة منجز شات».

## ٣. الضبط

- **الشكل**: اللون، والجهة (يمين أو يسار)، والبعد عن الحافّة، والعنوان، ورسالة الترحيب، والشعار، واللغة.
- **نموذج الزائر**: الاسم والجوال إجباريان دائماً. ويمكنك طلب البريد (اختياري أو إجباري)، وإضافة نصّ موافقة يجب أن يقبله الزائر.
- **السلوك**: إظهار الاسم الأول للموظّف للزائر، والصوت عند وصول ردّ، والسماح للزائر بإرسال الملفات (صور وفيديو وصوت وPDF وملفات Office، حتى ٣ ملفات في المرّة).
- **المواقع المسموحة**: اكتب دومين موقعك ليعمل الكود عليه وحده. `*.example.com` تشمل كل النطاقات الفرعية. اتركها فارغة للسماح بأي موقع.
- **المعاينة**: أسفل الصفحة نسخة حيّة من النافذة بإعداداتك المحفوظة، وتعمل حتى قبل التفعيل. ما تكتبه فيها يصل صندوقك كزائر حقيقي.

## ٤. كيف تبدو المحادثة عندك

- أيقونة **المحادثة المباشرة** بجانب اسم الزائر في صندوق المحادثات، ورقمه الذي كتبه تحت اسمه.
- في لوحة الجهة كارت **«الزائر»**: الصفحة التي يتصفّحها الآن، وأول صفحة دخلها، ومن أين جاء، ومتصفّحه.
- الزائر **جهة اتصال منفصلة** حتى لو كتب رقماً لعميل عندك على واتساب: الرقم لم يُتحقَّق منه، فلا نربط محادثاته بمحادثات غيره.
- لا نافذة ٢٤ ساعة: تردّ عليه متى شئت. القوالب وإرسال الموقع غير متاحة هنا (لا معنى لهما في المتصفّح).

## ٥. الردّ الآلي

يعمل كما في واتساب بلا إعداد إضافي:

- الردود الجاهزة بالكلمات المفتاحية.
- الـ flows: **الأزرار والقوائم تظهر للزائر أزراراً يضغطها**، وزرّ الرابط يفتح الرابط.
- المساعد الذكي (نصّاً وصوتاً).
- رسالة خارج أوقات العمل، واستبيان التقييم عند إغلاق التذكرة.

## ٦. الزائر الذي غادر

إن أغلق الزائر الصفحة قبل ردّك، يجد الردّ حين يعود إلى موقعك **من نفس المتصفّح**، وعلى الزرّ شارة بعدد الرسائل الجديدة. لا يصله بريد ولا رسالة واتساب.

## ٧. إن نُسخ الكود

الكود يحمل مفتاحاً عامّاً. إن ظهرت النافذة في موقع لا تملكه:

1. أضف دومينك في **المواقع المسموحة**، أو
2. **أنشئ مفتاحاً جديداً** — الكود القديم يتوقّف فوراً، فالصق الجديد في موقعك.
